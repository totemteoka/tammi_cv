# TammiCV — TopCV Homepage Clone

Clone giao diện trang chủ [TopCV.vn](https://www.topcv.vn/) bằng React + Vite + TypeScript.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở http://localhost:5173/

## Stack

- React 19 + TypeScript
- Vite 8
- Lucide React (icons)
- CSS thuần (theo palette TopCV: `#00B14F`)

## Các section đã clone

- Header + navigation
- Hero search + category panel + banner slider
- Việc làm nổi bật (filter, job cards, pagination)
- Thương hiệu Pro Company
- Thị trường việc làm / Trạm phản hồi
- Top ngành nghề, CV Builder, Công cụ
- Giải thưởng, App promo, Stats, Ecosystem, Press
- Footer + floating action bar
